# Phase 2: Character Analysis

## Purpose and boundary

Create evidence-grounded dossiers for each important character at the project's
starting point. This phase records current state and pressures; it does not
decide an arc or fill gaps for completeness.

Separate evidence, synthesis, editor direction, speculation, and unknowns.

## Required outputs

Create `characters/index.md` and one dossier per relevant character. Include:

- current state at the starting point;
- prior history and development;
- relationships, motivations, conflicts, competencies, and limits;
- thematic role and source-supported future pressures;
- unresolved facts and interpretive uncertainty.

Use source locators where applicable. A plausible future direction is analysis,
not an approved story decision.

## Completion check

Every relevant character has a usable dossier and no speculative biography,
ability, fate, or relationship is presented as source fact.
