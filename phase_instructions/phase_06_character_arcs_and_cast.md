# Phase 6: Character Arcs and Active Cast

## Purpose and authority

Translate approved architecture into character change and stable drafting state.
This phase cannot create plot authority. Return to assumptions or architecture
when an arc requires a new identity, event, ability, relationship, institution,
or interpretation.

## Character arcs

Create `arcs/index.md` and one file for each important character. State the
beginning, middle, and end; transformation and cost; relationship and political
movement; philosophical development; and the approved architecture points that
cause each change. Movement must alter conduct and future possibility.

## Active cast dossiers

Create `cast/index.md` as the Phase 8 roster. `characters/` records evidence,
`arcs/` records change, and `cast/` consolidates approved current state.

For each active character record story function, approved background,
competencies and limits, knowledge boundaries, pressures, relationships,
viewpoint and voice baseline, physical presentation, deliberate unknowns, and
reader-facing introduction needs. A dossier is author knowledge, not reader
knowledge; Phase 5 schedules introductions and Phase 8 realizes them in prose.

## Completion check

After an architecture change, update every affected arc and dossier. Phase 7 and
Phase 8 may rely on the cast only when all three layers agree.
