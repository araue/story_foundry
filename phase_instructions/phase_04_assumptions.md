# Phase 4: Assumptions

## Purpose and authority

Turn only the speculative bridges required for construction into explicit,
reviewable decisions. No speculative premise may govern architecture, arcs,
world building, or prose before editor approval.

## Required template

Create `assumptions/index.md` and one file per decision:

```markdown
# Title

## Problem
## Evidence and constraints
## Possible solutions
## Preferred solution
## Why
## Confidence
## Consequences and dependencies
## Needs editor approval?
```

Evidence comes first, recommendation second, and the editor makes the decision.
A preservation rule may itself be an approved assumption. If later work needs an
unapproved interpretation, historical event, faction, ability, technology,
ecology, spatial relation, or mystery answer, return here.

## Completion check

Phase 5 begins only when required assumptions are coherent, cross-referenced,
approved, and free of unresolved contradictions.
